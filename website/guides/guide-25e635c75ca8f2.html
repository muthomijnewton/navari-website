A little know-how goes a long way.

Sourcing Settings holds the app-wide settings. Open it from Sourcing → Settings → Sourcing Settings. It has five tabs, and two buttons at the top: Portal Signup Link and Invite Supplier (see Invitations and Sign-up).

Onboarding

Registration

Registration Mode - Invitation Only: only people you invite can create an account. Open to Public: anyone can sign up from the portal.

Invitation Valid For (Days) -Shown only for Invitation Only. It is recorded but not enforced yet. The set-password link in an invitation email expires according to Frappe's own password settings.

Contact Email - Shown on the sign-up page so businesses know whom to ask for an invitation.

Accept Supplier Applications - Shows Become a supplier on the portal.

Accept Customer Applications - Shows Become a customer on the portal.

Fallbacks

Used on approval when neither the application nor its onboarding type sets a value:

  • Fallback Supplier Group
  • Fallback Customer Group
  • Fallback Territory

Bidding

By default, sealed quotations open only when all of these are true: bids have closed, the RFQ's minimum number of quotations has arrived, and every committee member has confirmed. Tick an exception to relax that rule for all sealed bids:

Field What it does
Allow Opening Before Bids Close The committee may open quotations early. Opening early stops suppliers from submitting further quotations.
Allow Opening Below the Minimum Quotations The committee may open quotations even if fewer quotations than expected have been received.
Allow Any One Committee Member to Open The first committee member to confirm opens the quotations, without waiting for every member.
Create Purchase Orders on Award When an award is submitted, a draft Purchase Order is created for each winning Supplier Quotation, containing only the items that supplier won. When disabled, use Create → Purchase Order from the awarded Supplier Quotation.

Portal Transactions

Field Default What it does
Allow Customers to Create Sales Orders Off Customers can place orders through the portal. Each order arrives as a draft Sales Order for your team to confirm.
Allow Customers to Request Credit Notes Off Customers can select an invoice and request a credit note.
Email Customers About Decisions On Emails the customer when a credit request is approved, rejected, returned, or credited.

Notifications

Field Default What it does
Notify Applicant On Emails the applicant when the application is submitted, approved, rejected, or returned.
Notify Reviewers of New Requests On Emails reviewers when a new application arrives.
Reviewer Role Purchase Master Manager The role that receives those emails.
