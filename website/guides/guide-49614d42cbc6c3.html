A little know-how goes a long way.

Before setting up Nigeria Compliance via DigiTax, ensure that your environment, ERPNext instance, and compliance onboarding requirements are properly prepared.

The integration depends on both ERPNext infrastructure and approved access to DigiTax and NRS platform.

System Requirements

The application is designed to run on supported versions of:

  • ERPNext
  • Frappe Framework

Always refer to the repository release notes or compatibility matrix for the recommended versions - our github.

DigiTax Account Requirements

To use the integration, organizations must be onboarded with DigiTax.

This typically includes:

  • Registration with DigiTax
  • Provisioning of API credentials
  • Access to sandbox or production environments
  • Mapping of business compliance information

Access credentials are required before the integration can communicate with NRS services - register here,

ERPNext Configuration Requirements

The following ERPNext setup is recommended before enabling the integration:

Company Setup

  • Company records configured correctly
  • Default tax templates configured

Item Setup

  • Proper item codes configured
  • Tax categories assigned correctly

Customer Data

  • Valid tax details where applicable

Accounting Configuration

  • Taxes and charges templates configured
