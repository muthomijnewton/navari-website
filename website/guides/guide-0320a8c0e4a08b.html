Colonnes de Valeur

Un Bilan nécessite plusieurs montants par période sur une même ligne : valeur brute, amortissements et dépréciations, et valeur nette. Recréer ce tableau chaque année dans un tableur est fastidieux et peut facilement entraîner une déconnexion par rapport au grand livre.

Les colonnes de valeur du modèle de rapport financier OHADA sont des mesures nommées qui s’étendent sur chaque période de rapport. Laissez le tableau vide pour conserver une seule colonne de montant par période, comme dans ERPNext.

Les colonnes de valeur ne modifient que la présentation. Elles ne changent pas la manière dont les écritures sont passées.

Avant de commencer

  • Créer d’abord le modèle de rapport financier OHADA et ses postes.
  • Déterminer les mesures dont vous avez besoin. Ne pas ajouter de colonnes uniquement pour afficher plusieurs années, la périodicité s’en charge déjà.
  • Choisir les codes de colonne uniques et non utilisés comme références de ligne, par exemple Brut, Amort, Net.

Ajouter des colonnes de valeur]

  1. Ouvrir le modèle et accédez à Colonnes de valeur ;
  2. Ajouter une ligne par mesure et définir le code de colonne et le libellé ;
  3. Définir la portée de la période si l’indicateur doit apparaître uniquement pour la période en cours ou uniquement pour les périodes précédentes ;
  4. Optionnellement, définir un modèle de titre à l’aide de {libellé} et {période}. La valeur par défaut est {libellé}, {période} ;
  5. Définir les valeurs par défaut qui s’appliqueront à chaque ligne (type solde ou formule, telle que Net = Brut - Depr) ;
  6. Enregistrer, et remplacer les lignes individuelles dans les Paramètres des colonnes de valeur uniquement lorsque les valeurs d’une mesure doivent différer.

Dans le rapport, les mesures s’affichent en commençant par la période la plus récente. Pour les mesures BRUT et NET sur 2025 et 2026, les en-têtes sont Brut (2026), Brut (2025), Net (2026), Net (2025).

Champs de colonne importants

Champ Description
Code de colonne Code utilisé dans les formules et les paramètres de ligne.
Libellé Titre de base affiché aux lecteurs.
Période concernée Toutes les périodes, Période actuelle uniquement ou Périodes précédentes uniquement.
Modèle de titre Modèle d'en-tête facultatif.
Type de valeur Devise (par défaut), nombre décimal, entier ou pourcentage.
Masqué Calculer la mesure pour les formules mais n’est pas imprimé.
Colonne vide Imprimer uniquement l'étiquette. À utiliser comme séparateur visuel.
Type de solde par défaut Remplacer chaque ligne de données de compte pour cette mesure. Laisser vide pour conserver le type de solde de chaque ligne.
Par défaut : Formule Considérer la valeur par défaut comme un calcul (par exemple Brut - Amortissement sur chaque ligne de la colonne Net).
Formule par défaut / Filtre de compte Filtre ou formule par défaut. Un paramètre au niveau de la ligne prévaut toujours.

Effectuer des calculs en toute sécurité

Dans une formule :
- Une référence de ligne (TA) correspond à une ligne dans la même mesure et la même période.
- Un code de colonne (Brute) correspond à une autre mesure sur la ligne et la période actuelles.
Une formule circulaire (Net dépend de Brute et Brute dépend de Net) est rejetée lors de l’enregistrement.

Résolutions de problèmes

La colonne NET est erronée sur chaque ligne

Vérifiez que l’option par défaut est réglée sur Formule et que la formule par défaut s’applique à la colonne NET. Vérifiez ensuite si un paramètre de colonne de valeur au niveau de la ligne ne la remplace pas.

Un en-tête de colonne manque pour l’année dernière

La portée de la période est peut-être définie sur Période actuelle uniquement. Utilisez Toutes les périodes sauf si vous masquez intentionnellement les années précédentes.

L'enregistrement échoue en raison d'un code en double

Le Code de colonne doit être unique et ne doit correspondre à aucune Référence de ligne.
