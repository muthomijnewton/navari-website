A little know-how goes a long way.

Zambia Compliance via DigiTax supports synchronization of Items and Customers with ZRA SIS. Proper setup of master data helps ensure successful transaction validation and compliance reporting.

Item Setup

Items intended for submission to SIS should be configured with the required compliance classification details. These include values such as :

  • Item Classification
  • Taxation Type
  • Country of Origin
  • Packaging Unit
  • Unit of Quantity
  • Product Type
  • Item Type.

Items intended for submission to SIS should be configured with the required compliance classification details. These include values such as :

  • Item Classification
  • Taxation Type
  • Country of Origin
  • Packaging Unit
  • Unit of Quantity
  • Product Type
  • Item Type.

These values can be configured directly on the Item, inherited from the Item Group, or automatically populated from the defaults configured in SIS Settings. This helps reduce repetitive setup and improves consistency across items.

If an Item is not intended for synchronization with SIS, users may enable the option to prevent item submission. When this option is enabled, compliance classification fields are no longer mandatory for that Item.

Item Synchronization

When an Item is created or updated, the system checks whether the Item has already been submitted to SIS and whether an active SIS Settings configuration exists.

If automatic synchronization is enabled and the Item is eligible for submission, the Item details are automatically transmitted to SIS.

Items may also be submitted manually using the available SIS actions on the Item form. Depending on the current status, users can also trigger update or resubmission actions directly from the Item record.

Customer Setup

Customer synchronization is based on the Tax ID configured on the Customer record. When a valid Tax ID is available, the customer becomes eligible for synchronization with SIS services.

When a Customer with a configured Tax ID is created or updated, the system can automatically synchronize the customer information to SIS if automatic submission is enabled and an active SIS Settings configuration exists.

Customer records may also be submitted manually using the available SIS actions on the Customer form.

This synchronization helps ensure that customer information used during invoice processing remains aligned with compliance requirements and available within SIS workflows.
